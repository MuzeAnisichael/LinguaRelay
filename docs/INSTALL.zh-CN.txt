LinguaRelay v0.3.2 安装说明

LinguaRelay 是后台运行的实时翻译与离线字幕工具，支持中文、日语、英语、韩语手动选择和互译。

安装内容
1. 本安装包只安装应用运行环境，不捆绑大型模型文件。
2. 首次启动会先检查 LocalAppData、程序目录和已记录位置中是否已有完整模型。
3. 未找到模型时，你可以选择：
   - 均衡 Small（推荐）：识别质量更好，适合 16 GB 内存、较新的 6 核 CPU 或 NVIDIA GPU。
   - 轻量 Base：启动更快、占用更低，适合 8 GB 内存或低功耗纯 CPU 电脑。
   - 验证并复用已有模型目录。
   - 从已经下载的离线模型 ZIP 安装。
4. 首次启动后可在“用户设置 → 识别与翻译”或离线工作台中继续选择 Medium、Large-v3 Turbo、Large-v3 识别模型或 M2M100 1.2B 翻译模型。界面会先显示下载体积和硬件建议。
5. 所有模型都支持中、日、英、韩。模型下载可断点续传，并在本地校验后加载。

音频源
- 系统输出：捕获电脑所有播放声音。
- 指定进程：仅捕获目标进程及其子进程，需要 Windows 10 2004 或更高版本；受 DRM 保护的内容可能无法捕获。
- 麦克风：使用 WASAPI 输入设备，支持在运行中切换和断线重连。

录制与导入
- 悬浮窗可开始、暂停、继续或结束当前音频源的录制；结束后自动执行更准确的后期识别与翻译。
- 离线工作台可导入音频，或从视频中分离音轨；支持播放、波形定位、时间轴字幕编辑。
- 可导出 WAV、FLAC、MP3、VTT、SRT、ASS、TXT、CSV 和 JSONL。
- 录音与导入文件保存在 %LOCALAPPDATA%\LinguaRelay\projects；请确保磁盘空间充足。

隐私与大模型
- 默认实时识别和快速翻译在本机完成；只有主动录制或导入时才保存音频。
- 大模型修正默认关闭，可在“用户设置 → 大模型”中接入本地或云端 OpenAI 兼容服务。
- 启用云端修正时，字幕、目标语言、术语和少量前文会发送到用户配置的 API。
- API 密钥只从指定环境变量读取，不写入 LinguaRelay 配置文件。

卸载
- 可从 Windows“设置 → 应用”或 LinguaRelay“用户设置 → 存储与卸载”卸载。
- 卸载程序会分别询问是否删除大型模型，以及是否删除录音/离线项目/配置/字幕历史；两者默认保留。

本版本尚未进行 Authenticode 签名，Windows 可能显示未知发布者。请只从项目 GitHub Releases 页面下载安装包，并核对 SHA256SUMS.txt。
