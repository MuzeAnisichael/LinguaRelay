LinguaRelay v0.1.5 安装说明

LinguaRelay 是后台运行的系统音频实时翻译字幕工具，支持中文、日语、英语、韩语手动选择和互译。

安装内容
1. 本安装包只安装应用运行环境，不捆绑大型模型文件。
2. 首次启动会先检查 LocalAppData、程序目录和已记录位置中是否已有完整模型。
3. 未找到模型时，你可以选择：
   - 均衡 Small（推荐）：识别质量更好，适合 16 GB 内存、较新的 6 核 CPU 或 NVIDIA GPU。
   - 轻量 Base：启动更快、占用更低，适合 8 GB 内存或低功耗纯 CPU 电脑。
   - 验证并复用已有模型目录。
   - 从已经下载的离线模型 ZIP 安装。
4. 两种模型都支持中、日、英、韩；翻译模型相同。模型下载后会逐文件校验完整性。

隐私与大模型
- 默认识别和快速翻译在本机完成，程序不会保存原始音频。
- 大模型修正默认关闭，可在“用户设置 → 大模型”中接入本地或云端 OpenAI 兼容服务。
- 启用云端修正时，字幕、目标语言、术语和少量前文会发送到用户配置的 API。
- API 密钥只从指定环境变量读取，不写入 LinguaRelay 配置文件。

卸载
- 可从 Windows“设置 → 应用”或 LinguaRelay“用户设置 → 存储与卸载”卸载。
- 卸载程序会询问是否同时删除大型模型；配置与字幕历史默认保留。

本版本尚未进行 Authenticode 签名，Windows 可能显示未知发布者。请只从项目 GitHub Releases 页面下载安装包，并核对 SHA256SUMS.txt。
