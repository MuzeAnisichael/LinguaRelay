# LinguaRelay v0.2.0

v0.2.0 expands LinguaRelay from a system-output caption tool into a selectable Windows audio-source pipeline, and adds explicit high-quality local model choices.

## 下载

- `LinguaRelay-0.2.0-Setup-x64.exe`：推荐的当前用户安装包，带卸载程序。
- `LinguaRelay-0.2.0-Windows-x64-portable.zip`：便携版。
- `LinguaRelay-0.2.0.spdx.json`：SPDX 2.3 软件物料清单。
- `SHA256SUMS.txt`：发布文件校验值。

首次启动仍可直接下载或复用 v0.1.5 发布页中的 Small/Base 基础模型包；基础模型未变，因此本版本不重复上传约 2.4 GiB 的相同文件。

## 新增音频源

- **系统输出**：捕获默认或指定的 Windows 扬声器输出。
- **指定进程**：使用 Windows 原生进程回环，仅捕获目标进程及其子进程；应用重启后可按进程名恢复到新 PID。
- **麦克风**：选择默认或指定的 WASAPI 输入设备。

三种来源都可从托盘菜单或“用户设置 → 音频源”切换，并共用自动重连、有界缓冲和 16 kHz 单声道归一化链路。按进程捕获要求 Windows 10 2004 或更高版本；DRM 内容或绕过系统音频引擎的软件可能输出静音。

## 模型与质量档位

识别模型现在可以选择 Base、Small、Medium 或 Large-v3 Turbo。识别与翻译解码分别提供极速、均衡、精确档；识别硬件可选择自动、CPU 或 NVIDIA GPU，并可配置 INT8/FP16 等计算精度。

翻译模型可以选择默认的 M2M100 418M，或约 2.5 GiB 的可选 M2M100 1.2B。缺失的高级模型只在用户确认后下载，界面会先显示体积和硬件建议，下载支持断点续传。Medium/Turbo 实时使用建议 NVIDIA GPU，1.2B 翻译建议至少 16 GB 内存。

识别调用新增重复惩罚、重复 n-gram 抑制、压缩率/置信度/静音阈值，并让 Silero VAD 的最短语音、静音和边缘填充与实时切段参数一致，以减少重复文本、静音幻觉和断词。

## 大模型接入

大模型入口仍在“用户设置 → 大模型”。选择本地 OpenAI 兼容服务（如 Ollama、LM Studio）或 HTTPS OpenAI 兼容 API，填写模型 ID；云端密钥通过环境变量提供。推荐使用“完整句异步修正”，这样本地快译先显示，大模型失败或超时也不会阻塞字幕。

## 安装与隐私

安装包会检测并复用 Base/Small 基础模型包；软件会在保存高级模型设置时检测 Medium、Large-v3 Turbo 和 M2M100 1.2B。卸载应用时可选择一并删除所有本地模型与下载缓存；配置和字幕历史默认保留。原始音频默认只在内存中处理。

本版本尚未进行 Authenticode 签名。请只从本项目 GitHub Releases 下载，并核对 `SHA256SUMS.txt`。
