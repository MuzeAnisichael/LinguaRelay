# LinguaRelay v0.1.2

v0.1.2 is a Windows x64 Alpha maintenance release focused on user-controlled subtitle presentation and reducing noisy-audio hallucinations.

## Highlights

- A new tray-accessible user settings dialog controls the four-language route, translated/bilingual display, subtitle history, status line, and click-through behavior.
- Subtitle retention is configurable from 0 to 120 seconds. Zero keeps the latest subtitle until another caption replaces it.
- Source and translated captions have independent font family, size, and color controls. Background color, background opacity, and whole-window opacity are also configurable and applied immediately.
- The realtime tab exposes partial-ASR cadence, punctuation finalization, preferred segment length, and maximum caption duration. Pipeline-affecting changes are clearly marked as taking effect after restart.
- Short template-like Whisper hallucinations over music or silence, including “字幕制作人 Zither Harp”, “Subtitles by”, and equivalent Japanese/Korean credit prefixes, are filtered by default. The filter can be disabled in settings.
- Local ASR/translation models can be removed independently from the tray or settings page. The Windows uninstaller now asks whether to also remove the 1.36 GiB model pack; configuration and caption history remain by default.
- Windows file properties, package metadata, installer publisher, About dialog, and MIT copyright now identify the producer and copyright owner as Leeleelee.
- v0.1.2 reuses the unchanged, SHA-256-pinned v0.1.0 model package, so existing installations do not download models again.

## Assets

- `LinguaRelay-0.1.2-Setup-x64.exe`: per-user Windows installer (recommended).
- `LinguaRelay-0.1.2-Windows-x64-portable.zip`: portable application bundle.
- `LinguaRelay-0.1.2.spdx.json`: SPDX 2.3 software bill of materials.
- `SHA256SUMS.txt`: hashes for all attached v0.1.2 assets.

## Compatibility and safety

- Windows 10/11 x64; CPU runtime included. CUDA behavior depends on locally compatible CUDA 12/cuDNN 9 libraries.
- The binaries remain unsigned. Windows may show an unknown-publisher or SmartScreen warning.
- Raw system audio is not saved by default. Cloud LLM correction sends caption text only when explicitly configured.
