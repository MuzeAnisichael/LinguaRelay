# LinguaRelay v0.3.1

v0.3.1 is a Windows startup hotfix for v0.3.0. It preserves the complete recording, media import, offline recognition, translation, editing, and export workflow introduced in v0.3.0.

## 需要更新的人

如果 v0.3.0 启动时提示 `ImportError: DLL load failed while importing QtCore` 或“找不到指定的程序”，请直接安装 v0.3.1。安装程序会原位升级；已有模型、设置、字幕历史和离线项目不会被删除。

## 修复内容

- 隔离 PyInstaller 的 DLL 搜索环境，防止开发工具链中的 Poppler/ICU 文件混入应用；
- 启动时明确优先使用 Windows 系统目录中的系统 ICU；
- 在生成安装包前检查冻结包中是否存在外来 ICU 或构建路径污染；
- 对冻结的 `PySide6.QtCore` 依赖执行真实 DLL 装载冒烟测试。
