# LinguaRelay v0.3.2

v0.3.2 is the recommended Windows startup hotfix for v0.3.0. It includes the clean Qt/ICU packaging fix from v0.3.1 and safely handles an in-place upgrade from the affected installer.

## 如何升级

- **安装版**：直接运行 `LinguaRelay-0.3.2-Setup-x64.exe`。安装器会先删除 v0.3.0 遗留的冲突 DLL，再写入新版本；不会删除模型、设置、字幕历史、录音或离线项目。
- **便携版**：把 `LinguaRelay-0.3.2-Windows-x64-portable.zip` 解压到新的空文件夹，不要覆盖 v0.3.0 的旧目录。用户数据和模型默认位于 `%LOCALAPPDATA%\LinguaRelay`，可以继续复用。

## 修复与验证

- 阻止 Poppler/ICU 等开发工具链 DLL 混入 PyInstaller 产物；
- 启动时优先使用 Windows 系统目录中的系统 ICU；
- 安装升级时精确清理 v0.3.0 遗留的冲突 ICU/OpenSSL DLL；
- 构建阶段拒绝受污染的冻结包，并真实装载 `PySide6.QtCore`；
- 在隔离用户目录和无界面 Qt 平台下实际启动最终 `LinguaRelay.exe`。

## 下载文件
