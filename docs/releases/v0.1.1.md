# LinguaRelay v0.1.1

v0.1.1 is a Windows x64 Alpha maintenance release focused on feedback, live-caption cadence, readability, model reuse, and desktop polish.

## Highlights

- The overlay now replaces its loading placeholder when both local models are ready and Windows shows a one-time ready notification.
- Recognized source text is displayed before machine translation completes. Completed partial ASR and translation results are no longer hidden merely because a newer partial is queued.
- A stable sentence-ending period, question mark, or exclamation mark requests an immediate final segment. Short-pause splitting after six seconds and the ten-second hard cap remain safety fallbacks.
- The overlay can be dragged and resized from every edge/corner; geometry is persisted and can be reset from the tray.
- Setup and first launch discover existing model directories, verify every file, and avoid duplicate downloads. v0.1.1 reuses the unchanged v0.1.0 model pack.
- History is now searchable and filterable, shows the latest revision for each segment, exposes record details, and copies translations. SRT export uses only the latest revision.
- The executable, taskbar, shortcuts, tray, and installer use the new compact speech-relay icon.

## Assets

- `LinguaRelay-0.1.1-Setup-x64.exe`: per-user Windows installer (recommended).
- `LinguaRelay-0.1.1-Windows-x64-portable.zip`: portable application bundle.
- `LinguaRelay-0.1.1.spdx.json`: SPDX 2.3 software bill of materials.
- `SHA256SUMS.txt`: hashes for all attached v0.1.1 assets.

The approximately 1.36 GiB model pack is unchanged and remains available from the v0.1.0 release. Models are installed only after license consent and SHA-256 verification.

## Compatibility and safety

- Windows 10/11 x64; CPU runtime included. CUDA behavior depends on locally compatible CUDA 12/cuDNN 9 libraries.
- The binaries remain unsigned. Windows may show an unknown-publisher or SmartScreen warning.
- Raw system audio is not saved by default. Cloud LLM correction sends caption text only when explicitly configured.
