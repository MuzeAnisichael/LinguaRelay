# LinguaRelay v0.3.3

本版本优化大模型修正的可靠性、网络延迟和 Windows 安装包，并公开英语→中文的真实 OpenRouter 测试结果。

## 修正更稳定

- 同一段旧修订不再覆盖更新的字幕；发送前过滤已过期请求。
- 停止或关闭修正后，取消尚未发送的请求；已经发送的请求等当前网络操作结束，不再显示晚到结果。
- 修复上下文设为 0 时意外发送全部前文；长录音使用有界上下文。
- 离线精修遵守速率上限、可取消等待，连续失败触发熔断并保留快译。
- 拒绝截断、过滤或无效的大模型响应；增加取消、过期和队列拒绝统计。
- 使用持久 HTTP 连接；新增 OpenRouter 一键预设和低延迟/低价格路由选择。密钥仍只从环境变量读取，不会被打包。

## 实测结果

使用自编样本，不上传用户录音和字幕历史。204 次真实调用共 **$0.00635959**。

真实 M2M100 快译的 30 条英语→中文样本中：

| 模型 | 完整修正 p50 / p95 | 两秒内完成 |
|---|---|---:|
| Gemini 2.5 Flash Lite | 0.844 / 1.422 秒 | 30/30 |
| Qwen3 30B A3B Instruct | 0.937 / 6.047 秒 | 21/30 |

两模型各修复 12 条实质问题，但仍有遗漏；控制样本中也出现误改。因此推荐先使用 Gemini 的**完整句异步修正**，保留原文和快译。以上不是音频端到端延迟或总体翻译准确率，质量结论来自小样本模型辅助盲评。完整原始结果、费用、误改案例和复现方法见[测试报告](../benchmarks/OPENROUTER-v0.3.3.zh-CN.md)。

## 安装与打包

- 发布使用独立 Python 环境和精确版本锁，避免混入系统 Python 包。
- 清理无用 Qt PDF/虚拟键盘/QML 依赖，保留媒体功能和软件 OpenGL 回退。应用目录从约 407.9 MiB 降至 **368.3 MiB**，减少约 **9.7%**。
- 软件物料清单改为来自实际打包组件及原生组件锁，共 39 项，不再列出无关的 torch/pandas 等完整开发环境依赖。部分运行时辅助代码所属的构建工具包仍如实列出。
- 卸载不再递归删除应用目录；自行放入的模型、导出文件默认保留。模型目录检测明确区分“发现目录”和“校验完整”。
- 最终 EXE 自测真实初始化 Windows Qt 平台、隐藏设置/字幕/离线窗口，验证 SQLite、WAV→MP3→WAV 和媒体加载，无需用户模型或音频设备。

## 下载和升级

- `LinguaRelay-0.3.3-Setup-x64.exe`：推荐安装包，可覆盖升级；
- `LinguaRelay-0.3.3-Windows-x64-portable.zip`：解压到新的空文件夹；
- `LinguaRelay-0.3.3.spdx.json`：软件物料清单；
- `SHA256SUMS.txt`：文件校验值。

仍复用已有 Base/Small 模型包，不需要重新下载模型。不会自动修改大模型配置或开启云端修正。v0.3.0 的已知冲突 DLL 及本次淘汰的应用 DLL 在安装升级时按确切路径清理；用户数据目录不做升级清空。

## 验证与限制

本机最终 **206 项回归通过**，最终 EXE 自测和发布文件完整性检查通过。隔离安装器两次安装、旧 DLL 清理、已安装 EXE 自测及卸载回归全部通过；791 个应用文件移除，合成用户模型、导出字幕和配置保留。隔离变体使用与正式包相同的文件/升级/卸载逻辑，但独立标识、无注册项和快捷方式；它不是对用户现有安装的实际升级，也不代替干净 Windows 机器测试。见[本地验证记录](../benchmarks/v0.3.3-local-validation.json)。
