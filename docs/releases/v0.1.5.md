# LinguaRelay v0.1.5

v0.1.5 是实时性、可读性、首次安装和日常操作的综合优化版本。

## 主要变化

- 默认字幕由“6 秒后优先、10 秒硬上限”缩短为“3.2 秒后优先、6 秒硬上限”，并在稳定句末标点或分号处立即断句。
- 开头保持快速 partial，长语音自适应降低重复识别频率，减轻 CPU/GPU 队列积压。
- 新增识别上下文，可为会议主题、人名、产品和术语提供提示。
- 用户设置新增“大模型”页，可配置本地或云端 OpenAI-compatible 服务；Ollama/LM Studio 有快捷预设。
- 悬浮窗新增暂停、单双语切换、历史、设置和隐藏按钮；点击穿透时自动隐藏控件。
- 首次启动新增 Small 均衡版与 Base 轻量版模型选择，继续支持已有目录和离线 ZIP。
- 安装说明、模型选择建议、隐私提示和卸载文字已重写。
- 修复旧 partial 翻译覆盖较新识别预览的问题。

## 选择模型

- `LinguaRelay-0.1.5-models-small.zip`：推荐，识别质量更好，安装后约 1.36 GiB。
- `LinguaRelay-0.1.5-models-base.zip`：低占用，安装后约 1.05 GiB。

普通用户不需要手动下载模型 ZIP：运行安装版或便携版后，首次启动向导会选择并下载安装。离线环境可以提前下载对应 ZIP。

## 大模型接入

打开悬浮窗“设”或托盘“用户设置…”，进入“大模型”：

1. 选择“完整句异步修正（推荐）”。
2. 本地服务选择 Ollama/LM Studio 预设，或选择云端 OpenAI-compatible API。
3. 填写服务端实际模型 ID。
4. 云端密钥写入界面所示环境变量后重启 LinguaRelay。
5. 保存；服务地址或模型变化在下次启动生效。

本地快速翻译始终先显示。大模型超时或不可用不会中断字幕。

## 安装与安全

发布资产包含 Windows x64 安装包、便携包、两套可选模型包、SPDX SBOM 和 SHA-256 清单。模型包在安装时按应用内置清单逐文件校验。

本版本未进行 Authenticode 签名，Windows 可能显示“未知发布者”。请只从项目 GitHub Releases 下载并校验 `SHA256SUMS.txt`。
