# LinguaRelay v0.3.0

> [!WARNING]
> v0.3.0 的 Windows 发行包可能因 Qt/ICU DLL 冲突而无法启动，并提示无法导入 `QtCore`。请使用已修复并验证的 [v0.3.2](v0.3.2.md)；升级不会删除已有模型或用户数据。

v0.3.0 adds a complete recording and offline subtitle workflow without changing LinguaRelay's local-first real-time path. Record the current system, process, or microphone source; import an existing audio or video file; then generate, review, edit, and export time-aligned translations.

## 录制

悬浮窗新增三个紧凑入口：

- `●` 开始录制当前音频源；录制中该按钮变成 `■`，点击后结束并自动进入后期处理；
- `Ⅱ / ▶` 暂停或继续录制；
- `辑` 打开“录制与离线工作台”。

录制支持系统输出、指定进程及其子进程、麦克风三选一。录制内部使用分段 WAV：暂停会立即关闭当前片段，继续时创建新片段，暂停空档不会进入最终音频时间轴；真实暂停区间仍记录在项目数据库中。应用异常退出时，已经封口的片段可用于恢复。

当前录制格式针对语音识别优化为 16 kHz 单声道。它适合会议、课程和语音内容，不以高保真音乐录制为目标。录制期间不能切换音频源，以避免项目内格式或语义突然变化。

## 导入音频和视频

在工作台中选择“导入音频”或“导入视频”。PyAV 会读取第一个音轨，将其标准化为 16 kHz 单声道 PCM，并保留媒体时间轴。常见的 WAV、MP3、FLAC、M4A、AAC、OGG、Opus、MP4、MKV、MOV、AVI 和 WebM 可由随应用打包的 FFmpeg/PyAV 能力处理；具体容器能否打开仍取决于其中的编码格式。

导入与录制使用同一条后期流水线，因此项目、字幕编辑和导出行为一致。

## 高质量后期处理

后期模式与实时字幕相互独立：开始处理时会释放实时模型，避免同一 GPU/内存中同时驻留两套模型；任务完成后实时字幕自动恢复。

- `快速`：Beam 1，适合快速预览；
- `均衡`：Beam 5，默认推荐；
- `精确`：Beam 8，速度较慢，适合短音频精修；
- ASR 可选 Base、Small、Medium、Large-v3 Turbo 和 Large-v3；
- 默认启用 Silero VAD、前文条件和词级时间戳；
- 明确句末标点、时长和字符上限共同切分字幕，避免一条字幕堆积过多文字；
- “大模型精修”会使用“用户设置 → 大模型”中已配置的本地或 HTTPS OpenAI-compatible 服务逐条修正译文，并携带最近上下文与匹配术语。

Large-v3 Turbo 通常是后期任务的速度/质量平衡点。Large-v3 下载约 3.0 GiB、运行占用更高，适合有 NVIDIA GPU 或较短的高价值音频。纯 CPU 或长文件建议 Small/Medium 加“均衡”。

## 工作台与导出

项目和字幕保存在 `%LOCALAPPDATA%\LinguaRelay\projects`。工作台提供：

- 项目列表、处理状态、错误与进度；
- 本地播放、拖动定位和语音波形；
- 点击字幕跳转到对应音频位置；
- 可编辑开始时间、结束时间、原文和译文；
- 音频导出：WAV、FLAC、MP3；
- 字幕导出：WebVTT (`.vtt`)、SubRip (`.srt`)、ASS (`.ass`)；
- 数据导出：TXT、CSV、JSON Lines。

“MP3 + VTT”是两个独立文件：先导出同名 `.mp3`，再导出同名 `.vtt`，即可供大多数播放器或发布平台配套使用。

## 隐私、存储与卸载

实时字幕仍不会默认保存音频。只有用户明确开始录制或导入媒体时，音频才会持久化到离线项目目录。启用云端大模型精修会逐条发送原文、快速译文、最近文本上下文和匹配术语；不会上传项目音频。

卸载程序现在分别询问：

1. 是否删除本地模型和下载缓存；
2. 是否删除录音、离线项目、配置和字幕历史。

两个选项默认都为“否”，便于升级或重装后继续使用；若项目包含敏感音频，请在卸载时主动删除用户数据。

## 当前限制

- 源语言仍须在录制或导入前手动选择；
- 一个录制项目一次只使用一个音频源，暂不混录系统音频与麦克风；
- 暂无说话人分离与逐说话人字幕；
- 工作台会顺序执行一个后期任务，避免显存和内存竞争；
- 四语 `zh / ja / en / ko` 继续覆盖全部 12 个方向，更多语言按[语言扩展方案](../LANGUAGE-EXPANSION.zh-CN.md)逐步验证。
