# 开发路线图

## M0：项目基础（当前）

- [x] 明确 Windows 首发、固定英语到简体中文；
- [x] 建立公开仓库结构、MIT 许可、CI 和贡献指南；
- [x] 建立配置、领域事件、历史记录和悬浮窗演示；
- [x] 记录架构、模型许可和延迟预算；
- [ ] GitHub 仓库创建与首次推送（本机凭据恢复后完成）。

验收：`lingua-relay doctor`、`lingua-relay demo`、`pytest` 和 `ruff check .` 可运行。

## M1：音频捕获（预计 2–3 天）

- 枚举 WASAPI 输出设备并记住用户选择；
- 默认输出设备 loopback 捕获；
- 转为单声道 16 kHz float32，写入有界环形缓冲区；
- 支持设备断开、默认设备切换和静音；
- 实现音量计和 30 分钟无泄漏压力测试。

验收：播放测试音频时可持续产生带单调时间戳的 PCM 块；默认不落盘。

## M2：实时识别（预计 3–5 天）

- 集成 faster-whisper `small/int8`；
- 固定 `language=en`，明确禁止自动检测；
- VAD、重叠窗口和稳定前缀算法；
- partial/final 状态和丢弃过期 partial 的背压策略；
- CPU 与 NVIDIA GPU 基准脚本。

验收：30 分钟英语视频，字幕不中断，P50 首条 partial 不高于 1.2 秒；无无限增长队列。

## M3：即时翻译与完整悬浮窗（预计 3–4 天）

- 集成 OPUS-MT 英中模型；
- 原文/译文双行、partial 淡化、final 固定；
- 调整字号、位置、透明度、点击穿透和快捷键；
- 托盘菜单：开始/暂停、语言、设备、历史、退出；
- JSONL 历史与导出。

验收：快速译文 P50 不高于 1.8 秒；翻译失败时仍显示原文。

## M4：异步大模型修正（预计 3–5 天）

- 定义本地模型与 OpenAI-compatible API provider；
- 实现最近上下文、术语表、超时、熔断和速率限制；
- 支持“即时异步修正”和“会话结束后批量修正”；
- 用 revision 事件保留快速译文和修正译文；
- UI 明确显示本地处理或云端传输状态。

验收：关闭/断开修正 provider 不影响快速链路；任何修正都能追溯原译文。

## M5：质量与发布（预计 1–2 周）

- 构建包含会议、视频、口音和背景音乐的合法测试集；
- 记录 WER/CER、术语命中率、翻译质量和端到端延迟；
- 打包为 Windows 安装程序，首次启动按需下载模型并展示许可证；
- 崩溃恢复、自动更新策略、隐私说明和威胁建模；
- 发布 `v0.1.0`。

## 暂不进入初版

- 自动检测语言；
- 麦克风与系统音频混音；
- 按单个进程捕获音频；
- macOS/Linux；
- 多人说话人分离；
- OCR/屏幕文字翻译；
- 账号、云同步和团队协作。

这些功能只有在初版低延迟链路稳定并获得真实使用反馈后再排期。
