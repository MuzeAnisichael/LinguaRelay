# 开发路线图

仓库记录的公开版本是 **v0.3.2**；`main` 源码版本 **0.3.3 尚未公开发布**。本页回顾里程碑并列出候选顺序；逐项现状、验收证据与边界见[统一需求表](REQUIREMENTS.zh-CN.md)，历史意图见[项目上下文](PROJECT-CONTEXT.zh-CN.md)，当前任务见[交接](HANDOFF.zh-CN.md)。“已完成”表示对应功能里程碑已落地，不代表所有硬件/语言/场景达到全部性能目标；候选事项须另行确认范围，不是自动开发授权。

- [x] 明确 Windows 首发；
- [x] 将手动语言范围确定为简体中文、日语、英语、韩语，共 12 个互译方向；
- [x] 建立公开 GitHub 仓库、MIT 许可、CI 和贡献指南；
- [x] 建立配置、领域事件、历史记录和悬浮窗演示；
- [x] 记录架构、模型许可和延迟预算。

验收：`lingua-relay doctor`、`lingua-relay demo`、`pytest` 和 `ruff check .` 可运行。

- [x] 使用 `audio-select` 将用户选择保存到 `config.toml`；
- [x] 捕获默认或指定输出设备的 loopback 音频；
- [x] 将交错 PCM 流式转换为单声道 16 kHz `float32`；
- [x] 输出固定 320 ms 音频块和单调时间戳；
- [x] 使用有界新鲜数据优先缓冲，记录原始包与输出块丢弃数；
- [x] 支持静音连续性、默认设备变化检测、指定设备恢复和指数退避重连；
- [x] 实现 RMS/峰值音量计与低音量回环自检；
- [x] 实现 30 分钟持续运行、格式连续性和内存增长验收。

验收命令：

```powershell
lingua-relay audio-devices
lingua-relay audio-self-test
lingua-relay audio-stress --minutes 30 --report data/m1-stress.json
```

本机历史验收记录见 `docs/benchmarks/`。实时模式及该音频验收默认只在内存中处理音频，报告只保存设备和性能指标；v0.3 起用户主动录制或导入的音频会写入本地离线项目。

## M2：四语实时识别（已完成）

- [x] 集成 faster-whisper `base/small` 并完成 CPU INT8 / NVIDIA float16 基准；
- [x] 将 `zh / ja / en / ko` 作为显式 `language` 参数传入，禁止自动检测；
- [x] 针对中文、日语、英语、韩语实现在线端点检测、Silero VAD、重叠窗口和稳定前缀；
- [x] 建立 partial/final 状态和丢弃过期 partial 的有界背压策略；
- [x] 使用固定修订的 CC-BY-4.0 FLEURS 四语测试集；
- [x] 记录 WER/CER、首条非空 partial P50/P95、内存和持续运行表现。

M2 当时的本机验收采用 `small/CUDA float16`。四语首条非空 partial P50 分别为约 0.71 / 0.72 / 0.91 / 1.03 秒；每种语言通过重复固定样本累计处理超过 30 分钟音频，674 次推理错误数为 0，推理阶段墙钟约 214.4 秒、RSS 增长 5.84 MiB。这不是完整应用连续运行 30 分钟；当时窗口配置也不同于当前默认六秒。推理/事件队列容量有限、旧 partial 可替换，但 final 的等待有界性仍有 K-001 风险。报告见 [m2-small-cuda-final.json](benchmarks/m2-small-cuda-final.json)及[验证索引](VERIFICATION.zh-CN.md)；这些不是当前全场景保证。

## M3：12 方向即时翻译与完整悬浮窗（已完成）

- [x] 建立 `(source_language, target_language) -> translator provider` 路由表；
- [x] 通过固定版本 M2M100/CTranslate2 支持 `zh / ja / en / ko` 全部 12 个直接互译方向；
- [x] 使用单实例预热、LRU 缓存和有界队列，过载时替换旧 partial 并保留 final；
- [x] 本地模型覆盖全部方向，因此 M3 不启用远程 API 回退；provider 路由保留后续扩展点；
- [x] 支持“仅显示译文”和“双语同时显示”，partial 淡化、final 固定，翻译失败回退原文；
- [x] 支持字号、位置、透明度、点击穿透和全局显示/隐藏快捷键；
- [x] 托盘菜单支持开始/暂停、手动源/目标语言、设备、显示模式、历史和退出；
- [x] 支持 JSONL 历史及 JSONL/CSV/SRT 导出；
- [x] 准备 PyInstaller、独立模型包、Inno Setup 安装器和 GitHub 打包工作流。

功能验收：12 个方向都能运行并有独立基准，翻译失败时仍显示原文。快速译文 P50 ≤ 1.8 秒是性能目标；具体硬件结果和未达标项以[基准报告](benchmarks/README.md)为准。

### 本次建议先完成 0.3.3 的原因

当前源码、PE/安装器与脚本默认版本均为 0.3.3，尚未正式公开；优先收口而不是跳号。满 final 等待链路可能影响录制和退出，先建立确定性复现、保护录音并获得可信观测，再用数据选择体验优化。

正常工况和短暂拥塞保留已接收 final；持续过载时暂停受影响字幕分支并告警，录制继续，未接收/中止片段明确统计。不能通过静默丢句或无限等待维持“成功”假象。只解决队列与控制流等待，不承诺硬中断原生推理。没有主动录制时不新增音频落盘；自动保存积压后补译需独立确认。

本次默认源码推送，不自动创建 GitHub Release、标签或安装包；是否加正式发行需用户确认。付费 API 与模型下载不在默认范围，旧预算不复用。验证、失败记录、未测项与收尾步骤详见版本计划。

- 自动检测语言；
- 简体中文、日语、英语、韩语之外的语言；
- 麦克风与系统音频混音；

- 多人说话人分离；
- OCR/屏幕文字翻译；
