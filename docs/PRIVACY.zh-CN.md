# 隐私说明（v0.3.1）

LinguaRelay 默认在本机处理电脑输出音频。本项目没有遥测、广告、账号或云同步服务。

## 数据如何处理

- 系统输出、指定进程或麦克风音频通过 Windows WASAPI 捕获。实时模式只在内存中交给本地 ASR；只有用户明确开始录制时，语音优化的 16 kHz 单声道音频才会写入离线项目。按进程模式只把目标 PID 交给本地辅助程序，不读取目标进程的文件、命令行或窗口文本。
- 用户导入的音频/视频不会覆盖源文件。PyAV 在本机读取第一个音轨，并把工作副本写到 `%LOCALAPPDATA%\LinguaRelay\projects`。
- faster-whisper 与 M2M100 模型在本机执行。首次启动会从固定的 GitHub Release 地址下载基础模型包，并逐文件校验 SHA-256。用户选择 Medium、Large-v3 Turbo、Large-v3 或 M2M100 1.2B 时，应用会在确认后访问 Hugging Face 下载对应高级模型。
- 完整字幕默认以 JSON Lines 写入 `%LOCALAPPDATA%\LinguaRelay\history.jsonl`，以支持查看、导出和后期修正。可在配置中关闭 `history_enabled`，也可手动删除该文件。
- 配置、录音/离线项目、模型、下载缓存和最多 5 份崩溃报告位于 `%LOCALAPPDATA%\LinguaRelay`。离线项目数据库保存媒体路径、语言、时间轴、识别原文和译文；项目目录包含录音或标准化音频。崩溃报告不主动包含音频，但异常消息可能包含本地路径。
- 应用会向 GitHub Releases API 检查新版本，并在首次安装模型时访问 GitHub；选择高级模型时会访问 Hugging Face。服务方会按其政策看到常规网络元数据（例如 IP 地址）。更新只提醒，不会静默安装。

## 可选大模型修正

修正功能默认关闭。选择本地 provider 时只允许 loopback 地址。选择 OpenAI-compatible 云端 provider 时，应用会向你配置的 HTTPS 端点发送：源字幕、快速译文、最近文本上下文及匹配的术语表条目。API 密钥只从指定环境变量读取，不写入配置或字幕历史。

离线工作台启用大模型精修时会逐条发送文本，不会把项目音频上传到大模型端点。在启用云端修正前，请确认端点提供方的隐私、保留和跨境传输政策适合你的用途。不要把 v0.3.1 用于未经授权的监听、敏感或受监管音频。

## 删除数据

可在应用设置中删除全部本地模型。卸载程序会分别询问是否删除模型/下载缓存，以及是否删除录音、离线项目、配置和字幕历史；默认保留。退出 LinguaRelay 后删除 `%LOCALAPPDATA%\LinguaRelay` 可清除所有用户数据。
