# Support

LinguaRelay is an alpha open-source project maintained on a best-effort basis.

- Use [GitHub Discussions](https://github.com/MuzeAnisichael/LinguaRelay/discussions)
  for setup questions, model-selection help, and early ideas.
- Use the structured [issue forms](https://github.com/MuzeAnisichael/LinguaRelay/issues/new/choose)
  for reproducible bugs, translation-quality reports, performance measurements,
  and focused feature requests.
- Use a private [GitHub security advisory](https://github.com/MuzeAnisichael/LinguaRelay/security/advisories/new)
  for vulnerabilities or privacy issues.

Include the LinguaRelay version, Windows version, install type, model profile,
manual language route, and relevant hardware. Never attach private recordings,
API keys, or unredacted caption history.
